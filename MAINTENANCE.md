# Maintaining this profile

- `README.md` is displayed on [my GitHub profile](https://github.com/Himoryzhang). Edit it to change the live profile.
- `profile.json` is the original export from [GitHub Profile README Generator](https://rahuldkjain.github.io/github-profile-readme-generator/). Keep it for re-importing into that generator. Editing it alone does not update the README.
- The README retains all 31 selected skills and the selected profile sections. Skill links point to the corresponding official sites.
- `profile/top-langs.svg` is generated from public repositories by [GitHub Readme Stats Action](https://github.com/stats-organization/github-readme-stats-action), the maintained alternative recommended by the original GitHub Readme Stats project. The workflow uses the built-in GitHub token and does not include private repository statistics.
- The language card refreshes daily at 03:23 UTC (11:23 in China). You can also run **Actions → Update language card → Run workflow**. GitHub may delay scheduled runs or disable scheduled workflows in public repositories after 60 days without activity; if that happens, re-enable the workflow in Actions.
- The card is stored in the repository, so the last successfully generated image remains visible if a later refresh fails.

The repository must remain public and named `Himoryzhang` for GitHub to display its root README on the profile.
